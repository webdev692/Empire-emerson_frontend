# Fall 2026 Global Internship — Frontend Training Sandbox

This directory and the `training/fall-2026-sandbox` branch are learning infrastructure for Team Eclipse. They are intentionally separate from the production `main` branch.

## Purpose
Interns use this branch during the Foundation Academy and Controlled Application Labs to practice code review, Git/GitHub workflow, responsive UI, accessibility, information architecture, forms, testing, documentation, and responsible AI-assisted development.

## Non-negotiable boundaries
- Do not place real client, applicant, intern, financial, tax, insurance, health, credential, password, token, API-key, service-role, or other private data in this branch.
- Use synthetic, anonymized, or public-source data only.
- Do not connect exercises to production Supabase, Railway, Netlify production sites, production email, CRM, or social accounts.
- Do not merge this branch or intern exercise branches into `main` without explicit release approval from the authorized technical lead/founder.
- A preview or prototype is not permission to publish publicly.

## Recommended intern workflow
1. Read the WebDev Platform Orientation Pack and company/platform briefs in Drive.
2. Create an exercise branch from `training/fall-2026-sandbox`, not from `main`.
3. Use a branch name such as `intern/<github-username>/week-01-accessibility-audit`.
4. Make one focused change with clear commit messages.
5. Run available lint/build/tests.
6. Open a pull request back to `training/fall-2026-sandbox`.
7. Include screenshots/testing evidence without exposing private information.
8. Record the work in the weekly portfolio and attribution record.

## Suggested Weeks 1–4 exercises
- Repository orientation and architecture map.
- Component inventory and route map.
- Accessibility audit using WCAG-minded checks.
- Responsive-design review.
- Build a mock global-resource directory interface using synthetic records.
- Build a mock learning-resource card/search interface for EPDG.
- Improve validation/error-state UX on a sandbox form.
- Add or improve component-level tests and documentation.

## Weeks 5–8 transition
Only after lead review, interns may work on controlled company application laboratories. Staging work remains separated from production and follows the Access Register and release checklist.

**Training branch owner:** Team Eclipse technical leadership. **Final production authority:** Founder/authorized system owner.
