# Frontend Training Exercises

## Exercise 1 — Repository Orientation
Produce a one-page architecture note identifying the app entry point, routing, major component groups, styling approach, data-fetching patterns, tests, and build/deploy commands. Do not change production configuration.

## Exercise 2 — Accessibility and Responsive Audit
Select one existing page or component. Document keyboard behavior, labels, headings, contrast concerns, focus states, responsive behavior, empty/error states, and at least three prioritized improvements. Implement only in the training branch.

## Exercise 3 — EPDG Learning Resource Prototype
Create a sandbox interface for free learning resources with synthetic records. Include provider, topic, audience, cost label, credential availability, official-source URL field, last-verified date, and status. No scraping credentials or private user data.

## Exercise 4 — TEE Resource Navigation Prototype
Create a mock directory/search experience for housing, food, health/medical, education, humanitarian relief, or other essential-resource categories. Clearly distinguish resource indexing/referral from direct provision.

## Exercise 5 — TEA Financial Education Prototype
Create an educational resource page that distinguishes general financial education/resource navigation from regulated financial, tax, or insurance advice. Use placeholder/synthetic content only.

## Exercise 6 — Form UX and Validation
Build or improve a sandbox form using synthetic inputs. Include field validation, accessible errors, success/failure states, privacy notice, and no secrets in client code.

## Evidence expected in the weekly portfolio
- Problem statement and learning objective
- Branch and pull-request link
- Screenshots or test evidence
- What changed and why
- Accessibility/security/privacy considerations
- Collaborator attribution
- AI/tool disclosure when applicable
- Reflection and next step
